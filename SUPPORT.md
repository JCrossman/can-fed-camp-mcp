# Support

Use [GitHub Issues](https://github.com/JCrossman/can-fed-camp-mcp/issues) for
installation problems, bugs, and feature requests. Include the OS, Node.js
version, MCP host/version, install route, and minimal reproduction. Remove
cookies, notification URLs, account details, and other personal information from
logs before posting.

Security vulnerabilities must use
[private vulnerability reporting](https://github.com/JCrossman/can-fed-camp-mcp/security/advisories/new)
as described in [`SECURITY.md`](SECURITY.md).

The latest 1.x minor release is supported. Critical fixes may be backported to
the preceding minor release when immediate upgrade is disruptive. Parks Canada
and MCP host changes can break integrations without notice; compatibility fixes
are best effort. This community project provides no service-level agreement and
is not affiliated with Parks Canada or the Government of Canada.
